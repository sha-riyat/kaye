## Cerebral Valley project page

**Name:** Kayé

**One-liner:** An AI shop assistant for West African merchants, entirely inside WhatsApp.

**Description:**
In West Africa, small shops never adopted CRMs or ERPs: they run on a paper credit notebook and
WhatsApp. Kayé meets merchants where they already are. They speak, photograph or type in French as
they would to a relative, and Kayé keeps the whole shop: sales and credit, mobile money payments,
stock, expenses, supplier debts and due dates, sellers, daily summaries and polite reminders.

The model proposes, the merchant validates, the code writes. Muse Spark 1.3 turns each message into
typed tool calls; the code resolves customers, recomputes every amount, and writes nothing before the
merchant taps « Oui ». A long voice note with several operations becomes one recap with one button.
Muse Voice Transcribe handles French voice notes, Muse Spark reads handwritten notebook pages and
T-Money/Flooz screenshots, SAM 3.1 counts stock on a shelf photo, and Muse Image draws a logo for
shops that have none. Receipts go out as images the merchant forwards to the customer.

Deployed on a real WhatsApp Business number: +228 71 67 45 79.

**Built with:** Muse Spark 1.3, Muse Voice Transcribe 1.0, SAM 3.1, Muse Image 1.0, WhatsApp Cloud
API, Modal, FastAPI, Supabase Postgres, Cloudflare R2.

**Track:** Indie Developer · Theme: Build for Your World
